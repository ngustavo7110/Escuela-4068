Proyectos

Toca un proyecto para ver las conexiones y el código. Están ordenados de menor a mayor dificultad.

LED parpadeante

El primer programa: encender y apagar un LED. Nivel 1

Conexiones: pata larga del LED a una resistencia de 220 Ω y esta al pin 13. Pata corta a GND.

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

Semáforo

Tres LED que se encienden en secuencia. Nivel 1

Conexiones: LED rojo al pin 10, amarillo al 9 y verde al 8, cada uno con su resistencia de 220 Ω. Todos los cátodos a GND.

const int ROJO = 10, AMARILLO = 9, VERDE = 8;

void setup() {
  pinMode(ROJO, OUTPUT);
  pinMode(AMARILLO, OUTPUT);
  pinMode(VERDE, OUTPUT);
}

void loop() {
  digitalWrite(VERDE, HIGH);    delay(4000);
  digitalWrite(VERDE, LOW);
  digitalWrite(AMARILLO, HIGH); delay(1500);
  digitalWrite(AMARILLO, LOW);
  digitalWrite(ROJO, HIGH);     delay(4000);
  digitalWrite(ROJO, LOW);
}

Alarma con pulsador

Un zumbador que suena mientras mantienes presionado el botón. Nivel 2

Conexiones: pulsador entre el pin 2 y GND. Zumbador entre el pin 7 y GND.

void setup() {
  pinMode(2, INPUT_PULLUP);
  pinMode(7, OUTPUT);
}

void loop() {
  if (digitalRead(2) == LOW) {
    tone(7, 1000);
  } else {
    noTone(7);
  }
}

Termómetro digital

Mide la temperatura con un LM35 y la muestra en el monitor serie. Nivel 2

Conexiones: LM35 con la pata izquierda a 5V, la central al pin A0 y la derecha a GND (viendo el lado plano).

void setup() {
  Serial.begin(9600);
}

void loop() {
  int lectura = analogRead(A0);
  float grados = lectura * 5.0 * 100.0 / 1023.0;
  Serial.print(grados);
  Serial.println(" °C");
  delay(1000);
}

Servo controlado con potenciómetro

Gira el potenciómetro y el servo copia el ángulo. Nivel 3

Conexiones: servo: cable marrón a GND, rojo a 5V, naranja al pin 9. Potenciómetro: extremos a 5V y GND, centro a A0.

#include <Servo.h>

Servo servo;

void setup() {
  servo.attach(9);
}

void loop() {
  int lectura = analogRead(A0);
  int angulo = map(lectura, 0, 1023, 0, 180);
  servo.write(angulo);
  delay(15);
}

Medidor de distancia

Un sensor ultrasónico mide la distancia a un objeto en centímetros. Nivel 3

Conexiones: HC-SR04: VCC a 5V, GND a GND, Trig al pin 6 y Echo al pin 5.

const int TRIG = 6, ECHO = 5;

void setup() {
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  long duracion = pulseIn(ECHO, HIGH);
  float cm = duracion * 0.0343 / 2;
  Serial.print(cm);
  Serial.println(" cm");
  delay(300);
}
